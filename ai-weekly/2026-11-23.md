## Hugging Face Papers

- **[WeVisForensics: Self-Evolving Agent for Omni AI-Generated Video Detection](https://huggingface.co/papers/2611.21373)** — 腾讯提出自演化取证 Agent 框架：主调查 Agent 调度视觉与音频取证子 Agent，用双时间尺度强化学习（DTPO）决定"查什么、查多长、何时收手"。在域内、域外与 agentic 基准上平均检测准确率 95.2%，比最强前作高 9.0%，且结论能落到具体伪造片段。

- **[Mind2Act World: A Diagnostic Benchmark for Embodied Mind, Physical Action, and Mind-Action Composition in Robotic Manipulation](https://huggingface.co/papers/2611.26444)** — 具身智能诊断基准，分别测机器人的"心智理解、物理动作、以及两者组合"能力。目的是把"机器人做不好"拆成可定位的短板，而不是只看一个总成功率。

- **[WeMM-Video: Pushing the Frontiers of Open-Source Omni-Modal Video Understanding](https://huggingface.co/papers/2611.26409)** — 开源全模态视频理解模型，统一处理画面、音频与文本，试图把开源侧的视频理解上限往上顶。对需要"看视频并回答细节"的 Agent 是关键底座。

- **[Probing the "Conscious" Mind: Selective Access and Global Workspace in Vision-Language Models](https://huggingface.co/papers/2611.26590)** — 借认知科学的"选择性访问 / 全局工作空间"框架探测视觉语言模型内部表征，检验模型是否形成类似意识访问的功能结构。属于机制可解释性而非能力刷榜。

- **[Posterior Matching Distillation](https://huggingface.co/papers/2611.26629)** — NVIDIA 提出 PMD，用倾斜均值约束匹配教师扩散模型的完整后验，不需要辅助 score 网络，也能做任意步数采样。在 SDXL 与 FLUX.2 [klein] 4B 上，4 步生成取得同类最佳 FID，同时保持提示对齐与感知质量。

- **[Coda-DaVinci: Reimagining Video Generation with Code2Video](https://huggingface.co/papers/2611.26595)** — 用"代码生成视频"（Code2Video）重做视频合成：把镜头、运动、时序表达成可执行程序。相比纯像素扩散，可编辑性与可控性更强。

- **[Depth Pro 2: Sharp and Temporally Consistent Metric Monocular Depth](https://huggingface.co/papers/2611.26603)** — Apple 单目度量深度第二代，主打边缘锐利与视频时序一致。对 AR 遮挡、3D 重建与机器人避障都更实用。

- **[The Mask Is Not the Object: Volumetric Supervision for 3D Gaussian Segmentation](https://huggingface.co/papers/2611.21383)** — 指出 3D 高斯分割里用 2D mask 当监督会把遮挡与背景"学成物体"，提出体素级监督来纠正对象边界。是 3D 资产管线里很实际的一课。

- **[EgoCaptioner: Towards Comprehensive and Fine-Grained Egocentric Video Captioning](https://huggingface.co/papers/2611.26380)** — 面向第一视角视频的细粒度描述模型与数据方案，覆盖手部动作、物体交互与操作顺序。可用于第一视角助手、操作教学与具身数据标注。

- **[AltRA-Test: An Alternative Annotator Test for LLM Judges Without Shared Annotators](https://huggingface.co/papers/2611.26073)** — 在没有共享标注者的情况下检验 LLM judge 是否可靠，给出替代标注者检验方法。直击"用模型评模型"缺乏校准的痛点。

- **[HiUni: Harmonizing Understanding and Generation in Shared Visual Space](https://huggingface.co/papers/2611.26107)** — 在共享视觉空间里统一图像理解与生成，让同一套表征同时服务判别和合成。是多模态统一架构路线的新样本。

- **[TuringSpace: Grounding Spatial Intelligence in Action with Interactive CAPTCHAs](https://huggingface.co/papers/2611.25387)** — 用交互式 CAPTCHA 把空间智能"落到动作"：模型必须真的操作界面完成任务，而不是答选择题。为空间推理评测提供了一个更接近真实操作的形态。

- **[ZeroVLN: Learning to Navigate without Supervised Fine-Tuning of the VLM Brain](https://huggingface.co/papers/2611.26414)** — 探索不做 VLM 监督微调的视觉语言导航：冻结"大脑"，只学导航策略。对降低具身训练成本、保留通用视觉能力有意义。

- **[RL Post-Training in Diffusion Transformers Is Activation Steering](https://huggingface.co/papers/2611.26627)** — 论证扩散 Transformer 的 RL 后训练本质上是在做激活引导，为"不靠梯度、只改激活"的扩散模型对齐提供理论解释。

- **[Language Models Can Rewrite Their Own Weights](https://huggingface.co/papers/2611.21885)** — 让语言模型直接改写自身权重，探索权重空间里的自我更新与自我改进。若成立，模型迭代可能不再完全依赖外部训练管线。

- **[WAM-Policy: World Action Models with On-Policy Distillation for Quadrupedal Loco-Manipulation](https://huggingface.co/papers/2611.24011)** — 世界动作模型加在策略蒸馏，用于四足机器人的移动+操作。把世界模型的预测转成可执行控制，是具身控制的一条务实路线。

- **[Training Vision Models for LLM-Driven Weight-Space Programming](https://huggingface.co/papers/2611.26408)** — 训练视觉模型去接受 LLM 生成的"权重空间程序"，相当于让语言模型直接编程视觉网络。探索的是跨模型权重复用，而非提示词调度。

- **[Learning What Actions Change: Action Effect Matching for Dynamics-Faithful World Models](https://huggingface.co/papers/2611.25980)** — 用动作效果匹配让世界模型学到"哪个动作导致哪个状态变化"，提升动力学忠实度。世界模型常见的"画面好看但物理不对"问题有了针对性解法。

- **[WM^MLLM: Turning MLLMs into World Models](https://huggingface.co/papers/2611.24193)** — 把多模态大模型改造成世界模型，用其预测环境演化。思路是用现成大模型的语义先验补世界模型的数据饥渴。

- **[Accelerating Mixture of Block Attention via Dynamic Routing, KV-Centric Execution and Runtime Pipelining](https://huggingface.co/papers/2611.26268)** — 从动态路由、以 KV 为中心的执行、运行时流水线三处下手加速 MoBA 长上下文注意力。属于推理系统层的硬优化。

- **[AutoMaster: Autonomous Post-Training by Making the Same Model a Better Teacher](https://huggingface.co/papers/2611.26510)** — 让同一个模型兼任更好的教师，自主完成后训练，减少对外部强教师与人工标注的依赖。是"模型自己教自己"路线的新尝试。

- **[On-Policy Morphing into Hybrid Attention Models](https://huggingface.co/papers/2611.24809)** — 在策略训练中把全注意力逐步"变形"为滑窗+全局的混合注意力，兼顾长上下文与推理效率。适合把已有全注意力模型低成本改造成高效架构。

- **[Online Mistake Detection in Instruction-Conditioned Procedural Video](https://huggingface.co/papers/2611.25567)** — 在"按指令操作"的过程视频里在线检测错误步骤，可做培训纠错、质检与远程指导。

- **[Twice-Told Critiques: Claim-Level Homogenization of Peer Review in the LLM Era](https://huggingface.co/papers/2611.26286)** — 按 claim 粒度量化 LLM 时代同行评审意见的同质化：评审是否越来越像同一个模型写的。对学术评价体系是个预警。

- **[Teaching Vision-Language-Action Models to Stop Safely](https://huggingface.co/papers/2611.26239)** — 教 VLA 模型在不确定或危险时安全停机，而不是硬执行。机器人安全里"知道什么时候不做"往往比"做得更准"更重要。

- **[CompoundingKernel: Self-Improving from Zero to First](https://huggingface.co/papers/2611.19230)** — 从零开始自我改进的 kernel 生成方法，靠复利式迭代把算子写对、写快。对 GPU 算子自动化有直接价值。

- **[Embeddings vs. Grep: Rethinking the Dense Advantage in Code Search](https://huggingface.co/papers/2611.20455)** — 重新审视代码搜索：在仓库级检索中比较稠密向量与 grep/词法搜索，结论指向 grep 在很多场景仍更划算。对 Agent 的检索工具选型是务实提醒。

- **[SpecWM: Turning Verification into Refinement for Streaming World Models](https://huggingface.co/papers/2611.26211)** — 把"验证"变成"精修"，用于流式世界模型：边生成边用验证器纠偏，减少长时漂移。

- **[A CPU Inside an LLM: Zero-Gradient Compilation of Exact Circuits into Pretrained Weights](https://huggingface.co/papers/2611.26450)** — 零梯度地把精确电路"编译"进预训练权重，让 LLM 内部执行确定性计算。是权重空间编程的一个极端案例。

- **[TwinLab-Bench: Evaluating AI Scientists in Agentic Twins of Real Labs](https://huggingface.co/papers/2611.26248)** — 在真实实验室的"智能孪生"里评估 AI 科学家，检验其设计实验、操作仪器与分析结果的能力。比纯问答 benchmark 更接近科研闭环。

- **[System 1 agents: a method for local, reliable and fast agentic AI](https://huggingface.co/papers/2611.21053)** — 提出"系统 1"式 agentic AI：本地、可靠、快速，强调反射式决策而非长链推理。对延迟敏感的端侧 Agent 是一条不同路线。

- **[Direct3D-V3: Latent-Free Diffusion Transformers in the Native Voxel Domain](https://huggingface.co/papers/2611.26511)** — 在原生体素域做"免 latent"的扩散 Transformer，直接生成 3D 资产。省掉 VAE 编解码，结构更简单。

- **[Accord: Universal Online Metric Localization and Dense Mapping from one Camera and an IMU](https://huggingface.co/papers/2611.25279)** — 只靠单目相机加 IMU 做通用在线度量定位与稠密建图。对手机、机器人与 AR 设备都是低成本方案。

- **[VSpark: Speculative Decoding for Autoregressive Vision-Language-Action Models](https://huggingface.co/papers/2611.22666)** — 给自回归 VLA 模型做投机解码，加速机器人策略推理。把 LLM 的加速技巧迁移到具身模型。

- **[Do Probing and Steering Favor the Same Directions Within and Across Language Models?](https://huggingface.co/papers/2611.19499)** — 比较"探测"与"引导"在同一模型及跨模型中选择的方向是否一致。关系到可解释性结论能否直接用于模型控制。

- **[NarrowSpec: Draft Hidden Width Need Not Match the Target in Speculative Decoding](https://huggingface.co/papers/2611.23835)** — 指出投机解码的草稿模型隐藏宽度不必与目标模型一致，给出更灵活的"窄草稿"设计，降低草稿成本。

- **[Phantom Success, Silent Failure: Auditing the Success Checkers of Simulated Manipulation Benchmarks](https://huggingface.co/papers/2611.25179)** — 审计仿真操作基准的"成功检查器"，发现假成功与静默失败会系统性高估机器人能力。评测基础设施本身也需要被评测。

- **[One Prior, Two Dynamics: Repurposing Video Diffusion Transformers for Self-Supervised Latent Action Learning](https://huggingface.co/papers/2611.26617)** — 复用视频扩散 Transformer 做自监督潜在动作学习，一个先验适配两种动力学。为机器人从无标注视频里学动作提供路径。

- **[S1CogBench: What System One Decision Models Can and Cannot Do on Cognitive Experiments](https://huggingface.co/papers/2611.00911)** — 用认知实验测"系统 1"决策模型的能力边界：哪些直觉判断能做，哪些一做就露馅。

- **[DailySafe: Benchmarking Dynamic Safety Awareness in Everyday Multi-Turn Multimodal Interactions](https://huggingface.co/papers/2611.26298)** — 面向日常多轮多模态交互的动态安全基准，检验模型能否随对话进展识别新出现的风险，而非只过静态红线。

- **[PAD: Policy-Aware Data Valuation for Autonomous Driving](https://huggingface.co/papers/2611.25604)** — 面向自动驾驶的策略感知数据估值：按"对策略有多大影响"给数据定价，而不是只看多样性或标注成本。

- **[Squoosh Bench: Evaluating UX-1 on 318 Historical Website A/B Tests](https://huggingface.co/papers/2611.25200)** — 用 318 个真实历史网站 A/B 测试评估 UX-1 的界面优化能力。给"AI 做设计"提供了可回测的硬指标。

- **[In Situ Training of Optical Neural Networks by Coding Agents](https://huggingface.co/papers/2611.23875)** — 让 coding agent 在真实光学系统里原位训练光学神经网络。把 Agent 从"写代码"推进到"调物理实验"。

- **[AURA: AUdio-dRiven streaming Avatar](https://huggingface.co/papers/2611.26540)** — 音频驱动的流式数字人，强调低延迟与持续生成，适合实时直播、客服与虚拟主播。

- **[Suppressing the Shortcut Hidden Behind the Gains of VideoLLM Fine-Tuning](https://huggingface.co/papers/2611.25776)** — 揭示 VideoLLM 微调涨分背后的捷径（如只抓单帧或文本线索），并提出抑制方法以提升真实视频推理的泛化。

- **[PlayCraft: Designing Engaging Games from Agent Play Experience](https://huggingface.co/papers/2611.26624)** — 从 Agent 的实际游玩经验出发设计有趣游戏，让 AI 参与"玩—改—再玩"的设计闭环。探索的是游戏可玩性优化，而非单纯生成关卡。

- **[Time Series Structure Learning with Local Causal Parent Discovery](https://huggingface.co/papers/2611.26232)** — 时间序列结构学习，通过局部因果父节点发现降低全局搜索成本。对根因分析、金融与工业时序建模都有用。

- **[Inhabitant: An Agent Framework for Long-Horizon Human-Scene Interaction with Spatial Control and Quantitative Feedback](https://huggingface.co/papers/2611.25005)** — 长时程人-场景交互 Agent 框架，带空间控制与定量反馈。目标是让数字人/机器人在场景里"待得住、做得对"。

- **[Lang-SVG: Hierarchical Image Vectorization with Language Priors](https://huggingface.co/papers/2611.15941)** — 用语言先验做层次化图像矢量化，把位图转成结构清晰、可编辑的 SVG。对设计资产复用与图标生成很实用。

- **[TwinD: Generalizing Deepfake Detection from Blending to Entire Face Synthesis](https://huggingface.co/papers/2611.25935)** — 把深伪检测从"换脸融合伪影"推广到"整脸合成"，提升对新一代全生成人脸的泛化检测能力。
