## Claude Code Changelog

### Claude Code 2.1.326（2026-11-16）

**【Added · 新增】**
1. 支持在启用 Agent 团队（agent teams）时打开 Code Mode；已开启的会话现在会以 Code Mode 启动。
2. 当 `--allowedTools`、`--disallowedTools` 或 `--tools` 中出现看起来不完整的规则时，启动时给出警告。
3. 当管理员在会话中途加入 managed-mcp.json 导致 MCP 服务器停止加载时，新增消息解释原因。
4. `/status` 新增一行，说明当服务商或环境变量（如 `DISABLE_TELEMETRY`）关闭功能时的具体情况。
5. 当 plugin.json 中 author、homepage 等字段格式错误被忽略时，在 `/plugin` 与 `claude plugin list` 中提示。
6. 新增 Ctrl+O 显示被隐藏的启动通知。
7. 空提示中新增提示，说明请求失败后该如何操作。
8. 在子代理视图中新增 Esc 停止的页脚提示（按 Esc 可停止该子代理）。
9. 新增 `OTEL_RESOURCE_INCLUDE_HOST`，在 OpenTelemetry 资源属性中包含 host.name 与 host.id（默认关闭）。
10. 界面组件优化：mod 的 Box 增加 `overflowX="scroll"`，Text 增加 maxLines 与 `wrap="clip"`。
11. [VS Code] 新增 `claudeCode.promptSuggestions` 设置，可关闭提示词建议。

**【Changed · 变更（安全与权限为核心，逐条呈现）】**
- 会话内 mods 文件夹的编辑会更频繁地询问；沙箱命令可写入的文件夹更少；如果每次编辑都询问，检查其中是否有指向不可读或网络路径的链接并移除。
- 在启用 Claude Code + Cowork HIPAA 配置的组织中，终端与 VS Code 会话默认以 auto 模式启动；可用 `disableAutoMode` 关闭。
- 未设置模式的终端与 VS Code 会话，在组织策略尚未加载时改为默认 auto 模式（而非 Manual）。
- 会话中途加入的 managed-mcp.json 可在下一次检查时生效；要完全生效需重启已打开的会话。
- Code Mode 的 `$` shell 助手会拒绝部分有问题的值并报错，不会执行任何内容。
- auto 模式会拦截部分此前可运行的 shell 命令。
- macOS 上部分此前可运行的 Bash 命令改为询问或被拒绝。
- hook 的 `"decision": "block"` 在更多情况下保持阻断，因此总是输出该决策的 hook 可能开始拦截调用。
- 默认以 auto 启动的会话，会在设置加载后采用服务端管理的 defaultMode；若设置加载失败且无本地副本、策略失败或强制要求，则退回 Manual。
- HIPAA 组织的 auto 模式：直连 Anthropic API 时，现与其他组织一样由服务端分类器审查动作。
- Bash 沙箱在会话中部分情况下会保留状态，直到运行 `/sandbox` 或 `/cd`；Bash 可能先询问。
- macOS、Linux、WSL 上的沙箱命令默认不再写入部分敏感的 home 目录；部分可通过用户或托管设置中的 `sandbox.filesystem.allowWrite` 放行。

- Linux、WSL 上的 Bash 沙箱会在每条沙箱命令前创建部分缺失的 `--add-dir` 文件夹，使创建这些目录的命令可失败、跳过或落入其中。

- 开启沙箱时，macOS、Linux、WSL 上的 `/rewind` 会保留部分文件不动并报告为已跳过。
- 当自动放行关闭时，Bash 沙箱会在部分设置环境变量的命令前询问；无人值守运行可拒绝这些命令。
- Claude 的文件工具拒绝写入 Claude Code 的登录文件（如 `.credentials.json`）。
- Bash 权限检查会在更多触及登录文件的命令前询问。
- 部分文件工具拒绝写入设备文件与进程文件。
- 部分 cp、mv 命令改为先询问。
- 绕过权限模式下的部分工具调用改为请求批准，无人可问时拒绝。
- Bash 权限检查会对部分值过长、无法完成检查的命令询问，或在可能命中拒绝规则、无人可答时拒绝。

- 部分格式错误的 PowerShell 命令会被拒绝。
- 部分定义了与内建命令同名函数的 PowerShell 命令会被拒绝，以便 Claude 重命名。
- auto 模式忽略部分通配 shell 允许规则（如未指定程序或以 `$HOME` 开头的规则），交由安全检查判定。
