## Claude Code Changelog

### Claude Code 2.1.331（2026-11-23）

**Added（14）**

- 终端会话的 Code Mode 支持扩展到 Amazon Bedrock、Google Cloud 的 Agent Platform、Microsoft Foundry 与 AWS 上的 Claude Platform。
- Claude apps gateway 新增 `oidc.groups_jsonpath`：用一小部分 JSONPath（RFC 9535）从对象列表的匹配条目里读取 groups。
- `claude doctor` 新增 API 连通性小节：报告 API 是否可达、HTTP 状态或错误，或说明为何未测试。
- tap 模式语音听写自行停止时给出提示：15 秒未识别到语音，或达到 2 分钟上限。
- 新增 `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION`：在会截断压缩响应的代理后面请求未压缩的模型响应；官方暂不建议用于自托管 runner 或 Remote Control。
- Claude apps gateway 新增 `CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1`：当 `oidc.use_proxy: true` 时，即使设置了 `NO_PROXY`，登录请求也把 https IdP 的主机名交给代理。
- `claude_code.llm_request` trace span 新增 `gen_ai.usage.*`、`gen_ai.response.model` 与 `gen_ai.operation.name`；其中 `gen_ai.usage.input_tokens` 包含 prompt cache token。
- 插件 manifest 新增 `optionalDependencies`：随列出它的插件一起安装，但可单独禁用或卸载。
- [VSCode] 退出登录后若撤销 claude.ai 登录的请求未确认，给出警告与撤销页面链接。
- [VSCode] 发送超大选区或附件文本前给出提示；"Prompt is too long" 下提示具体是哪个部分过大、下一步怎么做。
