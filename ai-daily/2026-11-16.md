## 四、Claude Code Changelog（1 个版本：2.1.325，2026-11-13）

> 本次更新体量较大，重点强化沙箱安全、权限流程与 IDE 体验，下面分类呈现核心条目。

**【Added · 新增】**
- 在 VS Code 等集成终端新增提示：当 Claude 读取或编辑过 Jupyter notebook 后，提示可重跑 notebook 单元。
- 当组织策略拦截请求时，在错误信息下补充如何继续：运行 `/rewind` 修改消息，或运行 `/clear`。
- 当沙箱内的 git checkout / stash / autostash 无法更新 `.claude` 等受保护文件时，向 Claude 给出说明。
- [VS Code] 终端支持提示词建议，Tab 接受下一条建议；可在 settings.json 用 `promptSuggestionEnabled: false` 关闭。
- [VS Code] 新增不创建 API key 的 Console 登录；在 SSH/WSL/容器窗口登录 MCP 时新增粘贴重定向 URL 的输入框。

**【Changed · 变更，安全与权限为主】**
- 沙箱内 Bash 命令默认走常规权限流程；如需免提示运行，设置 `sandbox.autoAllowBashIfSandboxed: true`。
- 只读 git 命令在非本项目/未信任仓库中会先询问；要用 `--add-dir`（而非 additionalDirectories）来免提示。
- 定时任务与 `/loop` 在运行声明了 allowed-tools 或 hooks 的 skill 前会先询问；要无人值守需在 permissions.allow 加 `Skill(name)`。
- 沙箱拒绝向已添加目录中的 `.claude` 设置、skills、agents、commands、hooks 执行写入。
- 插件 MCP 包（`.mcpb`、`.dxt`）改为解压到 plugins 目录而非插件文件夹下的 `.mcpb-cache`，使只读插件目录可正常加载。
- 插件市场与插件下载在仅设置 `ALL_PROXY` 时改用 CONNECT 隧道；代理拒绝 CONNECT 时下载失败。

**【改进与修复（精选）】**
- 改进：子代理在达到输出 token 上限被截断时，会被要求更简短地重新给出完整答案，而非只返回结尾。
- 改进：插件推荐/安装提示明确告知"插件可在你的电脑上运行代码、访问文件与 shell"。
- 修复：zstd 压缩响应解码中的一个安全问题。
- 修复：第三方网关/Foundry 上的会话每轮都报上下文长度错误而不是自动压缩的问题。
- 修复：子代理使用独立模型时，文件读取与 MCP 结果按主会话模型计量的问题。
- 修复：Bash 权限检查中部分复合命令可不经询问直接运行的缺口。
- 本版本共含 14 项改进、88 项 bug 修复，完整清单见官方永久链接。

版本 2.1.325 永久链接：https://code.claude.com/docs/en/changelog#2-1-325
