**AI 生成的数学结果：矩阵乘法、分解与 Lean 证明**

- **矩阵乘法指数**：OpenAI 的模型给出与其 10 月上界匹配的下界，使 ω 恰为 **9/4**；此前没有任何非平凡下界。机制据称是一个显式的超线性电路下界。Bubeck 指出，结合 Lee 等人的结果，线性规划可在 n^{9/4} 求解，并可得到强多项式时间算法（Smale 问题）。Omri Weinstein 称若正确"真正超现实"，因为多数专家预期 ω=2。

  HelloGitHub 月刊第 128 期上线，本期收录 **42 个**开源项目，AI Agent 与开发效率工具占了很大比重。代表性的有：用约 **7 美元**的 ESP32-S3 开发板通过 AirPlay 读取 iPhone 屏幕、再模拟鼠标键盘实现 AI 自动操作手机；Vercel 开源的桌面自动化工具，通过操作系统无障碍 API 让 Agent 直接定位并点击原生应用控件；OceanBase 开源的 Agent 上下文服务，持久化项目决策、约束与进度，支持 Claude Code / Codex 跨会话续接；以及包含 40+ agents、70+ skills 的 Claude Code 游戏开发模板。

  其他项目覆盖终端星空图、跨平台抓包分析、AI 编码额度“灵动岛”、Rust 编写的 **30MB** 无头浏览器、纯 Go 跨平台桌面框架、WebGPU 实时海洋模拟、浏览器电路仿真、可微分计算机视觉库、物理建模语音合成等。第 128 期延续了“从可玩的小工具到企业级基础设施”的选材风格，适合按兴趣挑项目试玩。
